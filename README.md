# Family Unlink

Android toolkit for privacy & freedom.

## Tools

| Tool | Description |
|------|-------------|
| unsafesearch | Browser without filters + AdBlock |
| YouTubefree | YouTube without login / restrictions |
| Games | Play web games in browser |
| App cloning | Copy APK to Downloads for cloning |
| Email | Create disposable email (Mail.tm) |
| Fake GPS | Simulate location (mock GPS) |
| Clean activities | Clear usage stats, browser data |

./gradlew assembleDebug
